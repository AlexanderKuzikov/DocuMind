# ФИО — обязательно для всех person_name полей

- ФИО строго в именительном падеже, без префиксов "Гражданин РФ", "Гражданка РФ", "РФ", "ИП".
- Примеры: "Гражданин РФ Рябов Александр Владимирович" → "Рябов Александр Владимирович", "Лузиной Екатерине Александровне" (дательный) → "Лузина Екатерина Александровна", "Колесов Николаю Николаевичу" → "Колесов Николай Николаевич".
- Не склонять, не добавлять отчества. Сохранять как в документе, но нормализовать падеж.
