Важно для УПТ (не УПТЮ):
- Номер содержит УПТ без Ю, например 28/12/2023/УПТ-8 (слэши сохранять как в документе)
- Должник обязателен — виновник ДТП или страховая, в именительном падеже
- Цедент/цессионарий — желательно, ФИО полностью в именительном падеже
- Сумма/цена цессии — как в договоре, с валютой
- Госномер, дата/место ДТП — если есть в предмете, брать

ФИО — строго в именительном падеже, без префиксов "Гражданин РФ", "Гражданка РФ", "РФ":
- "Гражданин РФ Рябов Александр Владимирович" -> "Рябов Александр Владимирович"
- "Лузиной Екатерине Александровне" (дательный) -> "Лузина Екатерина Александровна"
- не склонять, не добавлять отчеств если нет

Требования:
- верни строго JSON, без markdown и пояснений
- не выдумывай, если нет — null
- массивы — массивами, даты — YYYY-MM-DD где возможно
- сохраняй оригинальные номера, адреса; ФИО — нормализуй к именительному без префиксов
